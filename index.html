모듈 2. 움직임과 조건으로 문제 해결하기

4차시

움직이는 공 만들기: 의도된 실패

목표: 움직임을 만들고, 공이 화면 밖으로 사라지는 문제를 관찰한다.

while Trueratevelocity

실습 코드 3: 사라지는 구조대 공
from vpython import *

scene_background(color.cyan)
box(pos=vector(0, -0.1, 0), size=vector(8, 0.2, 5), color=color.green)

hero = sphere(pos=vector(-3.5, 0.45, 1.3), radius=0.25, color=color.white)
hero.velocity = vector(0.05, 0, 0)

while True:
    rate(60)
    hero.pos = hero.pos + hero.velocity
관찰: 공이 계속 오른쪽으로 이동하다 사라집니다. 이것은 실패가 아니라 조건문이 필요한 이유를 발견하는 순간입니다.
5차시

조건문으로 문제 해결하기

목표: `if` 조건문으로 공이 벽에서 돌아오게 만든다.

실습 코드 4: 벽에서 돌아오는 공
from vpython import *

scene_background(color.cyan)
box(pos=vector(0, -0.1, 0), size=vector(8, 0.2, 5), color=color.green)

hero = sphere(pos=vector(-3.5, 0.45, 1.3), radius=0.25, color=color.white)
hero.velocity = vector(0.05, 0, 0)

while True:
    rate(60)
    hero.pos = hero.pos + hero.velocity

    if hero.pos.x > 3.7 or hero.pos.x < -3.7:
        hero.velocity.x = -hero.velocity.x
6차시

궤적으로 움직임의 흔적 남기기

실습 코드 5: 궤적 있는 공
from vpython import *

scene_background(color.cyan)
box(pos=vector(0, -0.1, 0), size=vector(8, 0.2, 5), color=color.green)

hero = sphere(
    pos=vector(-3.5, 0.45, 1.3),
    radius=0.25,
    color=color.white,
    make_trail=True,
    trail_radius=0.03

hero.velocity = vector(0.05, 0, 0)

while True:
    rate(60)
    hero.pos = hero.pos + hero.velocity

    if hero.pos.x > 3.7 or hero.pos.x < -3.7:
        hero.velocity.x = -hero.velocity.x

모듈 3. 마우스·키보드·소리로 상호작용 만들기

7~9차시

클릭 오르골 정원

목표: 마우스 클릭을 중심으로, 키보드와 소리를 더해 상호작용 작품을 만든다.

scene.mousekeysdownplay_note

통합 실습 코드: 클릭 오르골 정원
from vpython import *

scene_background(color.cyan)

label(pos=vector(0, 3.2, 0), text="무지개 정원 구조대", height=18, color=color.white)
label(pos=vector(0, 2.8, 0), text="마우스 클릭: 공 이동 목표 · ← → 또는 A D: 직접 조종", height=8, color=color.black)

box(pos=vector(0, -0.1, 0), size=vector(8, 0.2, 5), color=color.green)

colors = [color.red, color.orange, color.yellow, color.green, color.cyan, color.blue, color.magenta]
flowers = []

for i in range(7):
    x = -3 + i
    box(pos=vector(x, 0.15, 0), size=vector(0.08, 0.6, 0.08), color=color.green)
    head = sphere(pos=vector(x, 0.55, 0), radius=0.28, color=colors[i])
    flowers.append(head)

hero = sphere(pos=vector(-3.5, 0.45, 1.3), radius=0.25, color=color.white, make_trail=True, trail_radius=0.03)
flag = sphere(pos=vector(-3.5, 0.08, 1.3), radius=0.12, color=color.red)

target_x = hero.pos.x
garden_notes = ['도4', '미4', '솔4', '높은도4']
note_index = 0

while True:
    rate(60)

    if scene.mouse.clicked:
        click = scene.mouse.getclick()
        target_x = click.pos.x

        if target_x > 3.7:
            target_x = 3.7
        if target_x < -3.7:
            target_x = -3.7

        flag.pos.x = target_x
        play_note(garden_notes[note_index], duration=0.18, type='sine', volume=0.25)
        note_index = (note_index + 1) % len(garden_notes)

    keys = keysdown()
    if 'ArrowLeft' in keys or 'a' in keys:
        target_x = target_x - 0.06
    if 'ArrowRight' in keys or 'd' in keys:
        target_x = target_x + 0.06

    if target_x > 3.7:
        target_x = 3.7
    if target_x < -3.7:
        target_x = -3.7
    flag.pos.x = target_x

    if hero.pos.x < target_x:
        hero.pos.x = hero.pos.x + 0.04
    if hero.pos.x > target_x:
        hero.pos.x = hero.pos.x - 0.04

    for i in range(7):
        flowers[i].radius = 0.28 + 0.04 * abs(hero.pos.x - (-3 + i)) / 7

모듈 4. 팀 프로젝트와 GitHub 기록

팀 프로젝트 운영 흐름

  1. 팀장이 VPyLab 프로젝트를 만든다.
  2. 초대 코드를 팀원에게 공유한다.
  3. 팀원은 코드를 이어받아 하나씩 기능을 추가한다.
  4. 저장할 때 “한 일, 막힌 점, 다음 할 일”을 남긴다.
  5. GitHub 저장소와 Pages 링크로 프로젝트를 공유한다.
교사용 포인트: 완성물만 보지 말고 저장 이력과 항해 일지를 함께 평가합니다. 누가 어떤 문제를 발견했고, 어떻게 해결했는지 확인할 수 있습니다.

좋은 저장 메시지 예시

복사 가능한 저장 메시지 템플릿
제목: 클릭 이동 기능 추가
한 일: 마우스를 클릭하면 공의 목표 위치가 바뀌도록 했다.
막힌 점: 정원 밖을 클릭하면 공이 너무 멀리 갔다.
해결: x 위치를 -3.7부터 3.7 사이로 제한했다.
다음 할 일: 클릭한 위치에 소리와 색 변화를 추가하기.

아이디어 예시

클릭하면 별이 피어나는 밤하늘, 소리가 나는 무지개 정원, 방향키로 조종하는 우주 탐사선, 반딧불이 오르골, 날씨를 표현하는 3D 사운드 풍경

평가 루브릭

영역우수보통기초
표현3D·소리·상호작용이 아이디어와 잘 연결됨3D 장면과 일부 상호작용이 있음예제 수정 수준에 머묾
컴퓨팅 사고반복·조건·이벤트를 목적에 맞게 사용기본 문법을 일부 사용코드 의미 설명이 부족
문제 해결오류를 관찰하고 수정 과정을 기록문제를 해결했으나 기록이 부족도움 없이는 설명이 어려움
협업팀원 작업을 이어받고 기록을 남김역할 분담은 있으나 연결이 약함개인 작업 위주
기록저장 이력과 항해 일지가 과정 이해에 충분주요 저장은 남아 있음저장 메시지가 불분명

첫 수업 안내 문구

오늘 우리는 파이썬을 “외우기”보다 “써서 표현하기”로 시작합니다. 코드 한 줄이 공이 되고, 숫자 하나가 위치가 되고, 클릭 한 번이 장면을 바꿉니다. 처음부터 완벽한 코드를 쓰는 것이 목표가 아닙니다. 작게 만들고, 실행해보고, 이상한 점을 발견하고, 고치고, 그 과정을 기록하는 것이 목표입니다.
